# Hardware Architectures for Deep Neural Networks: Optimization and Efficiency via FPGA and ASIC

This repository contains the thesis *"Studio di Architetture Hardware per Deep Neural Networks: Ottimizzazione ed Efficienza Computazionale tramite FPGA e ASIC"*, developed at the University of Calabria.

The work investigates dedicated hardware accelerators to optimize the execution of Deep Neural Networks (DNNs) on resource-constrained embedded and edge devices. It specifically analyzes and compares two main optimization strategies:

* **Systolic Arrays on ASICs:** Maximizing computational efficiency and data reuse for complex matrix operations.
* **Approximate Computing on FPGAs:** Leveraging reduced-precision arithmetic and memoization to balance energy consumption, flexibility, and model accuracy.
